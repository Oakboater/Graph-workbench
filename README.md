# Graph Builder

A lightweight web tool for making clean scientific graphs directly in the browser. Built with plain HTML, CSS, and JavaScript using the HTML5 canvas, with no external libraries or setup required.

# Features

- **Graph types:** Line graph, Bar chart, Filled line, Scatter plot with line of best fit, and Histogram.
- **Custom axis scales:** Set exact tick marks for the X and Y axes (`Scale X` and `Scale Y`), or leave them blank for automatic scaling.
- **Multiple data sets:** Plot multiple lines or bar groups on the same graph with custom colours, line styles, point markers, bar patterns, and error bars.
- **Export options:** Download the finished graph as a high-resolution PNG image, or copy the equivalent Python (`matplotlib`) code.
